Справочник антиаритмических препаратов (ААП)

Класс IC — Блокаторы натриевых каналов (медленная диссоциация)

Применяются при ОТСУТСТВИИ структурного поражения миокарда.

Пропафенон Класс IC
CYP2D6 → метаболизм · Расчёт дозы по QRS
Доза: 150-300 мг × 3р/сут. Макс: 900 мг/сут. «Таблетка в кармане»: 600 мг однократно (450 мг при <70 кг). Эффективность: ~60-75% (6-12 мес.)
Противопоказания: ИБС/ИМ, ГЛЖ, ФВ<40%, Бругада, АВ-блокада II-III без ЭКС, QRS>120мс, тяжёлая печёночная недостаточность.
Мониторинг ЭКГ: QRS↑>25%→снизить/отмена; PR≥240мс→снизить; нагрузочный тест после стабилизации дозы для выявления частотно-зависимого расширения QRS.
Взаимодействия: ↑Дигоксин (P-gp); ↑МНО варфарина; ↑Метопролол/Пропранолол. CYP2D6 ингибиторы (флуоксетин) ↑экспозицию.
Флекаинид Класс IC
CYP2D6 · ~30% почками · Осторожно при КК<50
Доза: 50-150 мг × 2р/сут. Макс: 300-400 мг/сут. «Таблетка в кармане»: 200 мг однократно, при неэффективности + 100 мг через 1,5 часа (max. 300 мг). Эффективность: ~50-70% (6-12 мес.)
Противопоказания: ИБС/ИМ, ГЛЖ, ФВ<40%, Бругада, АВ-блокада без ЭКС, QRS>120мс, КК<40 мл/мин.
Мониторинг ЭКГ: QRS↑~12-20% ожидаемо, >25%→снизить; нагрузочный тест после стабилизации дозы.
Взаимодействия: Амиодарон ↑уровень Флекаинида (снизить дозу); CYP2D6 ингибиторы; ↑Дигоксин (минимально).
Аллапинин ★ Класс IC
Печёночный метаболизм · <10% почечная экскреция · Ваголитический эффект!
Доза: 25-50 мг × 3р/сут. Ретард: 25-50 мг × 2р/сут. Принимать ПОСЛЕ ЕДЫ (запивать прохладной водой). Эффективность: ~50-60% (6-12 мес.)
Противопоказания: ИБС/ИМ, ГЛЖ≥14мм, ХСН III-IV, тяж. печ./почечн. нед., АВ-блок II-III, внутрижелуд. блокада, Бругада.
Мониторинг ЭКГ: QRS↑>25%→снизить/отмена; PR≥240мс. Мониторинг печени при длит. терапии.
Взаимодействия: β-АБ — усиление антиаритм. эффекта. НЕ сочетать с амиодароном/соталолом. НЕ повышает уровень дигоксина (преимущество перед Пропафеноном/Флекаинидом).
Этацунорм (этацизин) ★ Класс IC
Печёночный метаболизм · Доп. блок Ca2+-каналов · Ваголитический эффект!
Доза: 50 мг × 3р/сут. Титрация до 200-300 мг/сут. Под ЭКГ-контролем (через 2-3 дня). Эффективность: ~45-60% (6-12 мес.)
Противопоказания: ИБС/ИМ, ХСН, ГЛЖ≥14мм, полная блокада ножек пучка Гиса, тяж. печ./почечн. нед., АВ-блок.
Мониторинг ЭКГ: QRS↑>25%→снизить/отмена; проверка через 2-3 дня; QTc обычно не изменяется (низкий риск TdP).
Взаимодействия: НЕ сочетать с Соталолом/Амиодароном (↑риск аритмии). β-АБ — риск брадикардии/АВ-блокады. Холинолитик — оптимален при вагус-индуцированной ФП (после еды, ночная).
Класс III — Блокаторы калиевых каналов

Применяются при структурном поражении миокарда И при персистирующей ФП (электрическое ремоделирование).

Амиодарон ★ Класс III
Мультиканальный (ICr/IKs/IK1 + INa + ICaL + β) · Минимальная обратная частотная зависимость
Доза: НАГРУЗКА: 600 мг/сут × 1-2 нед → 400 мг/сут × 1-2 нед → 200 мг/сут (поддержание). Эффективность: ~50-75% (6-12 мес.)
Противопоказания: АВ-блок без ЭКС, выраж. брадикардия, тяж. тиреоидная дисфункция, тяж. патология лёгких/печени, беременность.
Мониторинг ЭКГ: QTc↑ ожидаемо (само по себе реже вызывает TdP <1% vs «чистых» IKr-блокаторов). Мониторинг: ТТГ/Т4 каждые 3-6 мес; АЛТ/АСТ каждые 6-12 мес; Рентген ОГК ежегодно; осмотр офтальмолога.
Взаимодействия: Варфарин -25-50% дозы (↑МНО); Дигоксин -50% (мониторинг ЭКГ); ↑Дабигатран ~50%; ↑Эдоксабан ~40%; Флекаинид ↑; Множ. CYP3A4/P-gp взаимодействия.
★ ЕДИНСТВЕННЫЙ ААП без ограничений при сниженной ФВ ЛЖ.
Соталол ★ Класс III + β
L-соталол: β-блокада · D+L-соталол: блок Ikr · Выраженная обратная частотная зависимость!
Доза: СТАРТ В СТАЦИОНАРЕ: 80 мг × 2р/сут → титрация до 160-320 мг/сут (шаг ~3 дня, контроль ЭКГ). Эффективность: ~30-50% (6-12 мес.)
Противопоказания: ФВ<20%, QTc>450мс исходно, КК<40мл/мин, K+<4,0ммоль/л, бронхоспазм, ХСН с декомпенсацией, удлинённый QT, беременность.
Мониторинг ЭКГ: QTc↑40-100мс ожидаемо при 160-320 мг/сут. QTc≥500мс → снизить/отменить! Не начинать при QTc>450мс. Риск TdP↑ при брадикардии, гипоK+/гипоMg2+, женском поле, почечной нед.
Взаимодействия: Диуретики → гипоK+/гипоMg2+ (↑риск TdP); QT-продлевающие ЛС — избегать; β2-агонисты — менее эф-вны; Дигоксин + недигидропиридиновые БКК — аддитивная АВ-блокада.
★ Место: ИБС/ИМ с СОХРАННОЙ ФВ при противопоказаниях к Амиодарону.
Дисклеймер. Калькулятор предназначен для медицинских работников и не заменяет клиническое решение врача. ESC 2024 рекомендует использовать шкалу CHA₂DS₂-VA без учёта женского пола; в данном инструменте женский пол показан как модификатор. Показатели годового риска являются ориентировочными. Решение о назначении препаратов принимается индивидуально.
Сокращения и источники

Сокращения

ФП — фибрилляция предсердий; ТП — трепетание предсердий; ААТ — антиаритмическая терапия; УЛВ — устье легочных вен; ЭИТ — электрическая импульсная терапия; ОАК — оральные антикоагулянты; ПОАК — прямые оральные антикоагулянты; КК — клиренс креатинина; ХСН — хроническая сердечная недостаточность; ОНМК — острое нарушение мозгового кровообращения; ТИА — транзиторная ишемическая атака; ИМ — инфаркт миокарда; ЗПА — заболевание периферических артерий; ГЛЖ — гипертрофия левого желудочка; ФВ ЛЖ — фракция выброса левого желудочка; ПИКС — постинфарктный кардиосклероз.
